# manual-review

Scores `docs/manual/` against an eight-dimension quality rubric — strip
executability, reference duplication, anchor stability, glossary
linkage, running-example continuity, maturity honesty, cli.md currency,
and diagram-source presence — each dimension graded pass/warn/fail with
file:line evidence, landed as a dated report. See [`SKILL.md`](SKILL.md)
for the full rubric and procedure.
