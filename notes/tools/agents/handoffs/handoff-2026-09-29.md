## Technical Notes

- **RNG replay without the toolchain.** The sandbox cannot resolve
  Maven; `java` is present. The engine's `:world` stream is
  `java.util.Random` seeded `mix64(mix64(seed, 3), 0)` (family tag
  `:world` = 3, id-tag 0; constants in `streams.clj:53-68`). Draw
  order: `patients-1` gap draws (`rand-int-in 0 2`, inclusive),
  then one selection uniform per ordinal, then two scheduling draws
  per ordinal (uniform, then `rand-int-in 3 21`). Selection index is
  `min(N-1, floor(u·N))` over alive count N. `patient-id-for` is
  `PID-%06d-%08x` of `mix64(seed, ordinal) & 0xffffffff`. This
  located the colliding pair at 6,000 before any Clojure ran, and
  it's how step 5's candidates were found.
- **`bin/ehrt` is `exec clojure -M:ehrt "$@"`** — no JVM-option
  pass-through. Heap is `clojure -J-Xmx8g -M:ehrt …`. The measuring
  host's default `MaxHeapSize` is 3.88 GB; the 22,500 cell sat at it.
- **`figures.edn` has two kinds of cell** (`:asserted` rewritten by
  the exerciser, `:quoted` hand-measured and dated). A downstream
  witness is a third kind; decision taken: reproduce in-tree, enter
  as `:quoted`, cite their run.
- **Downstream's config is re-serialized** (hash-map key order,
  commas) and produced byte-identical output — the engine reads
  config as a value.
- **Three ORU-rendered kinds** share `ORU^R01`: `:result-available`
  and `:diagnostic-report` carry ORC/OBR; `:observation` renders
  without (`registry.clj:133-152`). That's the wire rule for
  bucketing MSH-10 duplicates by kind.
- **Regression oracle vs bracket.** `bin/ground-truth-bracket`
  digests the `:ground-truth` half only; `bin/regression-oracle`
  digests the `{:ground-truth :hl7}` pair and takes
  `--declared-digest-change`. Two roots (`dermatitis`,
  `veteran-self-harm`) carry a present-but-empty `:hl7` half, so an
  emission-only change leaves 5 roots IDENTICAL, not 3.

## Watch-Outs for Successor

- **Roadmap rows carry populations that age.** Row 3 said 6
  duplicates in `:result-available` and 1 in clinic-decade; the
  corpus said 8 in `:observation`/`:diagnostic-report` and 10. Before
  ruling a fix shape on a row, regenerate the root and count.
- **Gates that read one root.** The conformance MLLP tripwire
  watched `seed-424242-clinic-decade` and never saw the four ADT
  collision classes live at dense-7500. When a gate asserts a
  property of "the corpus," ask which one.
- **Enumerated cohorts.** `dense-7500/config.edn` lists module
  ordinals to 7,496 and module rows to match. Any `--patients` above
  7,500 silently changes the module fraction. Downstream's 32k
  corpus has a 7,500 corpus's 937 module-walked subjects.
- **Deferred-effect guards.** Any new step that answers a guard with
  `:prepend-steps` rather than an event is a candidate for the
  same-instant race. Ask: two of these at one `t`?
- **The 22,500 figures in docs are stale twice over** (pre-ADR-0180
  walls, default heap). Downstream's 28k cell ran in six minutes.
- **`MEMORY.md` on penny** was reconstructed by the executor from a
  loaded index after a `sed -i` truncation. Glance before trusting.
- **Executor halts are the discipline working.** Twice this arc it
  measured a premise and stopped. Prompts that phrase mechanism as
  expectation, not ruling, let it do that cheaply.

  made MSH-10 carry it. Every rendered message now names its event
  by position; describe's witnesses, downstream joins and mutation
  lineage all key on the same thing. Minted by nothing, total,

- **Emission-only vs. ground-truth-moving** is the line downstream
  cares about. Their retained corpus is a ground-truth file; wire
  changes cost them re-rendering, ground-truth changes cost them
  requalification. Every change notice should say which side it is
  on before it says anything else.
- **A merge is a records correction, not a movement.** Ratified
  downstream 22 Sep: the survivor holds the physical bed, the
  absorbed registration's bed returns to ready with no cycle — the
  same class as the two cancels. `vacate-bed`'s docstring should say
  so (step 4).

  decide cannot read a future fold). Downstream's witnesses couldn't
  tell because nothing moved between order and result; a transfer in
  between would.

## What Worked Well / What To Do Differently

**Worked.** Fresh clone before every claim, including re-verifying
each executor landing with a string-and-comment-stripped code
compare rather than trusting suite counts. The Java stream replay.
Lettered options with one recommendation; mg's rulings came back as
single tokens ("1. 3 2. ok. 3. wait"). Downstream's evidence bundles,
once we named exactly what to send.

**Do differently.** Measure the corpus before ruling a shape on a
row. Confirm downstream delivery before layering a reply on a prior
one. Size a fix before promising a date — row 3 was "one session"
until it was a halt, an ADR and a session. Don't leave the executor
an unfilled ADR-form slot; it got filled by accident.
