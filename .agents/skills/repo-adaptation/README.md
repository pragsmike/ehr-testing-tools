# repo-adaptation

Inspects a repository, determines whether it needs bootstrap or
migration, and creates or proposes a standardized AGENTS.md +
`.agents/`-based layout with compatibility guidance. This workspace's
own `.agents/plans/2026-08-01-migration-report.md` and the migration
sessions executing it are this skill adapted in place and run against
itself. See [`SKILL.md`](SKILL.md) for the full trigger conditions and
workflow, and `references/compatibility-matrix.md` for this repo's own
empirical findings about tool-discovery paths.
