## What this repo is

Clojure/Polylith workspace generating deterministic synthetic hospital
traffic (Synthea GMF at pinned commit `7e08387c...f902`), injecting
defects, judging conformance (HL7v2/FHIR). Formats are emitters of the
patient state machine `[A]` (`notes/adr/` index: ADR-0043's own
"sibling emitters over one state machine" doctrine). Book repo
`ehr-testing-guide` is separate, permanently out of scope (ADR-0001
R2). A stranger can watch that traffic breathe as a bed board (`ehrt
play PATH --board N`, player arc, ADR-0066–0067), or generate and
replay a demo from a top-level operator front door (`demos/`, demos
front door, ADR-0073), without reading a line of this project's own
source. Twenty-three Synthea GMF ailments are vendored in-tree at the
project's own pinned commit, byte-verbatim, NOTICE-hashed, and
gate-verified on every test run (vendoring arc, ADR-0069–0074) —
untouched this arc. **New this arc (quality-review, ADR-0075–0080):** a
periodic, rubric-driven review discipline (`repo-review`, eight
dimensions) now stands alongside the alignment/UX arcs' own
survey→register→rule→fix→close pattern, and a production I/O call that
can fail now routes through one shared, gated vocabulary
(`ehrt.kernel.io`) instead of failing silently — a real, demonstrated
silent-success path (`corpus mutate` on a failed directory listing)
closed as this arc's own opening act.
