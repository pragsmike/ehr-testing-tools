## Judgment calls and their ratification status

- **The `stmarys.edn` illustrative-example exemption, disclosed rather
  than silently widening the gate.** `docs/simulate-your-facility.md`'s
  own walkthrough uses `--config stmarys.edn` as a placeholder the
  READER is meant to author and save themselves (the surrounding prose
  already says the shipped `demos/` examples are the exact, runnable
  ones) — it can never resolve from workspace root under any
  correction, since it was never meant to be a repo path. Rather than
  weaken the new gate's own rule generally, one narrow, named exemption
  (`illustrative-path-exemptions`, a single `[file value]` pair with
  its own comment) was added instead — not a silent skip, disclosed in
  ADR-0060's own enumeration table.
- **U4's "check `ehrt.kernel` first" instruction resolved to "confirmed
  absent."** A fresh grep for `similar|did-you-mean|suggest|sibling|
  same-stem|levenshtein|fuzzy` across the whole `components/kernel/`
  tree found nothing — the register's own hint was speculative, not
  confirmed. `similar-sibling-config` landed as a small local fn in
  `run.clj`, disclosed as local rather than reused, which also matches
  the session's own Fences (src edits scoped to `merge-config-file`
  and its namespace, not `ehrt.kernel`).
- **`result->exit-code` needed no new entries — confirmed by
  inspection, not assumed.** Its mapping keys only on `:status` (plus
  one named `:gate-no-verdict` category exception, unrelated here), so
  any `result/error` whose category isn't that one already reaches
  exit 2 through the existing catch-all. This matches C-1's own
  register recommendation ("no dispatch-layer change needed") exactly.
- **Two pre-existing tests the register didn't name, found only once
  the fix ran, fixed forward and disclosed.** `main-bang-bare-
  invocation-prints-usage-and-exits-two-test` (a `main!`-level
  duplicate of the dispatch-level bare-invocation assertion) needed
  the same exit-0 flip the register's own B-5/D-1 rows anticipated at
  the dispatch level, but the register didn't separately name this
  deeper `main!`-level test. Renamed, assertions flipped, disclosed
  here rather than left red or silently deleted.
- **The B-6/D-3 fix is uniform across every `unknown-command-error`
  call site, not special-cased to `sim`.** The register's own evidence
  focused on `ehrt sim` (a real group missing its verb), but the fix
  — deriving the hint from whether `(first args)` names a real
  top-level group — applies identically at every call site
  (`artifact`, `corpus`, `corpus generate`, `gate`, `sim`, and the
  top-level unknown-group case itself, which correctly keeps the
  generic hint since a genuinely-unknown token never matches a group
  name). One test pins the `sim` case explicitly per the register's
  own evidence; the uniform mechanism covers the rest without
  additional tests, disclosed here as a deliberate generalization
  beyond the register's literal wording.
