## Judgment calls and their ratification status

- **Premise mismatch, fixed forward, disclosed.** The prompt's own
  read-first list named "the fixes-2 gates as style models" — but
  session 2 (error surfaces) is this prompt's own *successor*, per its
  closing line, and had not run yet; no `ux-fixes-2` gate exists to
  read. Resolved by using this repo's actual nearest style precedent
  instead: `ehrt.docs-tooling.stale-path-test` (the closest existing
  gate — a forbidden-string family scoped by an explicit scan-source
  function, same shape this gate needed) and
  `ehrt.docs-tooling.tag-law-test` (the most recent gate in the family,
  landed the same day). Not a silent substitution — recorded here per
  the fix-forward-with-disclosure rule
  (`docs/dev/way-of-working.md` §2) rather than guessed past quietly.
- **Fresh grep reproduced the register's own count exactly — 11 files,
  14 instances, zero delta.** AR-U1-1 required disclosing a delta in
  either direction; there was none to disclose. Recorded as a positive
  finding in ADR-0059's own delta table rather than silently assumed.
- **A-3's licensed-optional cosmetic fence conversion
  (`docs/simulate-your-facility.md:202`) was declined**, not taken.
  It carried no `clojure -M:cli` instance and touching it would have
  widened the diff beyond this session's own single-purpose fence
  (the stale-alias sweep and the module-mix pairing fix only).
  Disclosed in ADR-0059 per A-3's own "disclose the choice either way"
  license — not a silent skip.
- **`--emit hl7`'s placement in the corrected module-mix commands**
  (before `--format er7`, not after) was chosen to match this
  codebase's own established flag-order convention already visible in
  `persona-enriched/README.md` and `boarding-transfer/README.md` (both
  already order `--emit hl7 --format er7`) — a judgment call, not
  dictated by `docs/cli.md`'s own grammar (either order parses), not
  separately ratified.
- **The new gate landed as its own file**
  (`invocation_lint_test.clj`), not folded into the existing
  `stale_path_test.clj` family file, because its scan-source scope
  (README.md, AUTHORS-GUIDE.md, `docs/**`, `components/*/docs/**`,
  `.md` and `.edn` both) differs from that file's own narrower
  `docs/`-plus-one-`.edn`-plus-four-named-`.agents/`-files scope — a
  same-family, different-file choice, following the same pattern
  `tag-law-test.clj` already set as its own separate family member.
